# 《经济研学动态》单篇 LaTeX 模板

将本目录复制到编辑部的单篇稿件工作目录。保留 `main.tex` 和 `jingyan.cls` 在同一目录，修改 `main.tex` 的示例内容。文档首页从文章标题开始，右上角为刊名，页码从 1 开始。

| 内容 | 写法 |
| --- | --- |
| 标题与公开署名 | `\ArticleTitle{文章标题}{作者姓名}` |
| 摘要 | `\ArticleAbstract{摘要正文}`，可省略。 |
| 关键词 | `\ArticleKeywords{关键词一；关键词二}`，可省略。 |
| 章节 | `\section`、`\subsection`、`\subsubsection` 自动编号。 |
| 表格 | 参照 `main.tex` 的三线表示例，用 `\caption` 添加表题，紧接 `\label`，正文用 `表~\ref{标签}` 引用。 |
| 引用与文献 | 用 `\TextCite` 和 `\ParenCite` 写作者—年份引用，用 `References` 和 `\Reference` 列出文献。 |

标题、署名和摘要会直接写入网站文章目录，请使用纯文本。百分号、与号等 LaTeX 特殊字符用 `\%`、`\&` 等方式转义。示例引文和文献条目须换成实际引用。插图可放在稿件目录的 `images/` 下，通过 `\includegraphics` 引入。

## 编译与发布

在稿件目录运行两遍 XeLaTeX，第二遍更新交叉引用。

```powershell
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

也可以在 Overleaf 中选择 XeLaTeX 并编译 `main.tex`。使用替代字体时请检查断行与分页。

网站发布时，将复制后的 `main.tex` 交给网站发布脚本，另外指定文章 ID 和发表日期。脚本生成单篇 PDF 和 `catalog.json` 待审文件，发表日期由网站用于归档。详细命令见网站项目根目录的 `README.md`。
