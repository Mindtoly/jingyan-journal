# 《经济研学动态》网站产品方案

## 产品定位

《经济研学动态》是用于交流经济学学习与研究成果的在线出版平台。网站按篇持续出版。每篇文章使用独立的文章 ID 和 PDF，发表后按年月归档。读者可浏览和检索已发表文章，编辑部负责保存稿件、审核发布版本并确定发表日期。

## 栏目与阅读体验

站首提供刊名和文章检索入口。主导航按下表顺序排列，四个栏目等距居中。

| 栏目 | 内容 |
| --- | --- |
| 文章列表 | 首页默认栏目。提供年月归档、文章列表、摘要和 PDF 阅读入口。 |
| 投稿须知 | 提供投稿邮箱、分阶段附件清单、LaTeX 模板下载及参考文献引注与著录体例。 |
| 通知公告 | 按发布日期倒序，每页展示 10 条标题和日期。正文展开时按需加载，同页可同时展开多条。 |
| 关于我们 | 介绍刊物及其用途，使用编辑部确认可公开的内容。 |

页脚使用酒红色通栏，展示刊名、简介和栏目入口。底部显示「© 2026 经济研学动态」和「本站刊载的文章仅代表作者个人观点。」

### 浏览、检索与阅读

- **归档。** 站点已有发表稿件时，文章列表显示日期筛选。归档年份由实际发表日期生成，默认展开最新年份并选中最近有发文的月份。没有已发表文章的月份显示为灰色并禁用。桌面端显示左侧日期面板。移动端从屏幕左侧用图标打开全高抽屉，选中月份后收起。
- **文章列表。** 桌面端按标题、作者和发表日期三栏展示。移动端标题独占一行，作者和日期排列在下一行。点击标题在新标签页打开对应 PDF。文章有摘要时可按需展开，默认折叠。
- **检索。** 检索覆盖已发表文章的标题、作者和摘要，范围跨越全部归档月份。清空检索后回到所选月份。
- **页面状态。** 正式目录为空时显示「暂无已发表文章。」无检索结果时显示「未找到相关文章。」文章目录加载失败时提供重试入口。

## 文章数据与发表规则

| 字段 | 用途与规则 |
| --- | --- |
| `id` | 文章的唯一标识。编辑部登记新稿时分配 `article-` 加六位流水号，从 `article-000001` 起，对应 `<id>.pdf`。同篇修订沿用原 ID。 |
| `title` | 从 LaTeX 定稿取出，显示在列表中，并作为 PDF 链接文字。 |
| `author` | 从定稿取出公开署名。 |
| `date` | 编辑部确定的发表日期，格式为 `YYYY-MM-DD`。网站按中国标准时间判断是否已到发表日，并按该日期归档。 |
| `abstract` | 从定稿取出的纯文本摘要，稿件省略摘要时存为空字符串。 |

正式数据集中保存在 `public/articles/`。其中 `catalog.json` 是全站共用的文章目录，PDF 与目录同级。待审目录中的 `catalog.json` 只记录对应的单篇文章。每次发布都将通过审核的 PDF 和目录记录一并写入正式数据。

## 编辑部发布流程

1. 编辑部在 `文章ID登记.csv` 分配文章 ID，按该 ID 整理 LaTeX 定稿和编译资源，并确定发表日期。
2. 通过 `prepare` 生成待审 PDF 和单篇目录。核对正文版本、公式和图表、交叉引用以及网站展示字段。修订后生成新的待审目录，保留文章 ID。
3. 审核通过且按北京时间已到发表日后，用 `publish` 将获批版本写入正式数据。替换已发表稿件时明确使用 `--replace`，沿用现有 PDF 路径。
4. 重新构建并预览静态站点，确认归档、检索和 PDF 与审核版本一致。部署本次生成的 `dist/`，在公开地址复核文章条目和 PDF。

模板和命令示例见[单篇 LaTeX 模板说明](../templates/article/使用说明.md)和[网站 README](../README.md)。

## 构建与上线

网站使用 Vue 3、Vite、Bootstrap 5 和 BootstrapVueNext。正式开发、构建和构建预览使用 `public/articles/`。部署对象为 `dist/` 中的静态站点，其 `articles/` 目录包含正式目录与 PDF。

计划使用 GitHub Pages 托管。首次上线时确认发布仓库、公开地址和所用部署方式。
